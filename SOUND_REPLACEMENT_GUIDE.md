To customize:
1. Replace a file with your own using the exact same filename. No code changes.
2. Or use MP3/OGG/WAV with another filename and edit sounds.js.

The included generated audio is a functional baseline. For cinematic realism, replace any cue you want with licensed or personally owned audio. Ambience replacements should be seamless loops when possible.
